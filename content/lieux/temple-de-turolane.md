# Présentation

Le Temple de Turolane n'a pas encore été visité par les joueurs.

Il est uniquement mentionné dans un journal retrouvé sur un campement de morts-vivants.

Aucun personnage ne donne d'information supplémentaire à son sujet.

# Ce que dit le journal

Le journal mentionne trois éléments :

| Élément mentionné  | Informations                                    |
| ------------------ | ----------------------------------------------- |
| Marché             | Un marché a été conclu avec une force inconnue. |
| Offrande           | Une offrande est mentionnée.                    |
| Temple de Turolane | « Le passage sera bientôt prêt. »               |

La formulation exacte laisse entendre qu'un lien existe entre le Temple de Turolane et un « passage », mais aucune précision supplémentaire n'est donnée.

---

# Liens connus

| Élément                     | Nature du lien                                  |
| --------------------------- | ----------------------------------------------- |
| Force inconnue              | Un marché aurait été conclu avec elle.          |
| Offrande                    | Mentionnée dans le même journal.                |
| Passage                     | Le journal affirme qu'il sera « bientôt prêt ». |
| Campement des morts-vivants | Le journal est retrouvé dans ce campement.      |

Aucun lien explicite n'est établi entre ces éléments.
