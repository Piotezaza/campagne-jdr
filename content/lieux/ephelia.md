## Généralités

- Éphélia est un pays situé au nord-est du monde.
- Sa position est comparée à celle de la Russie sur Terre, même si le climat est totalement différent.
- C'est un pays extrêmement sauvage, où la nature domine presque entièrement.
- Les traces de civilisation sont rares : très peu de constructions humaines sont visibles.

---

# Géographie

Éphélia est composé d'une grande diversité de milieux naturels :

- forêts tropicales (très majoritaires) ;
- jungles ;
- montagnes ;
- marécages ;
- volcans.

Le territoire est présenté comme très vaste.

---

# Déplacements

Le principal moyen de transport mentionné est le **[Pétale Doré](./petale-dore.md)**.

Il s'agit :

- d'une immense carriole ;
- d'une taverne roulante ;
- d'une auberge mobile ;
- tirée par d'immenses animaux.

Elle sert :

- de transport longue distance ;
- de taxi entre différentes étapes ;
- d'auberge itinérante.

Elle traverse principalement Éphélia, mais peut également voyager dans d'autres pays.

# Situation actuelle

Le pays traverse une période difficile.

Deux phénomènes sont mentionnés.

## La Fleur Noire

Une fleur appelée **Fleur Noire** (ou une fleur devenue noire) serait responsable de nombreuses disparitions.

Les personnages ne savent pas :

- ce qu'elle est réellement ;
- comment elle agit ;
- si elle tue ou fait seulement disparaître les victimes.

---

## Le [Roi des Rats](../pnj/roi-des-rats.md)

Depuis son apparition :

- la situation est encore pire ;
- les disparitions sont plus nombreuses.

Les personnages ignorent :

- son identité ;
- son apparence ;
- sa nature ;
- ses motivations.

---

# Disparitions

Les disparitions semblent être un phénomène important dans tout le pays.

- [Alias](../pnj/alias.md), le fils de [Martha](../pnj/martha.md).

Le groupe comprend rapidement que ces disparitions constituent probablement le cœur de leur aventure.
