# 1. Résumé chronologique

## Exploration après le combat

Après avoir vaincu les morts-vivants, le groupe poursuit brièvement son exploration de la zone où Livia a été enlevée.

Ils découvrent qu'un passage mène vers le nord. En s'y engageant, ils trouvent un énorme arbre dont l'écorce est particulièrement dure.

Livia identifie cette écorce comme un matériau pouvant être utilisé pour renforcer temporairement une armure.

Le groupe récupère un morceau d'écorce avant de rebrousser chemin.

---

## Retour au Pétale Doré

Le portail étant toujours ouvert, les personnages retournent dans le Pétale Doré.

À leur arrivée :

- le portail disparaît derrière eux ;
- Ponsard leur demande ce qu'il s'est passé ;
- il explique que les bêtes tractant le Pétale Doré ont brusquement pris peur.

Baba est toujours gravement blessée (1 PV).

---

## Les soins de Baba

Ponsard et Mintaros préparent une boisson spéciale.

La préparation contient :

- une boisson alcoolisée très forte ;
- quelques gouttes d'un liquide doré extraites d'une petite larve lumineuse.

Après avoir bu la préparation :

- Baba récupère l'intégralité de ses points de vie ;
- elle entre temporairement dans un état d'euphorie et de confiance extrême ;
- Mintaros prévient qu'un important mal de tête apparaîtra le lendemain matin.

Le groupe profite ensuite d'un repas offert.

---

## Partie de cartes

Ponsard propose un jeu de cartes ("AlphaCart 21").

Participent :

- Baba
- Bois
- Livia

Zarock refuse de jouer.

Première manche :

- Baba perd 1 PO.
- Bois remporte 5 PO.
- Livia remporte 16 PO après avoir discrètement triché sans être démasquée.

Deuxième manche :

- Baba perd 1 PO.
- Bois perd 4 PO.
- Ponsard remporte les mises.

---

## Préparation de la nuit

Ponsard explique que :

- les bêtes voyagent principalement la nuit ;
- elles se reposent lorsque le soleil se couche ;
- le Pétale Doré repartira durant la nuit.

Le groupe reçoit gratuitement :

- le repas ;
- la nuit à l'auberge.

---

## Les fleurs de Lueur Nocturne

Bois montre les fleurs récupérées précédemment.

Hortia explique leurs trois utilisations.

Les fleurs permettent :

1. de produire une lumière semblable à une lanterne pendant environ une à deux heures lorsqu'elles infusent dans l'eau ;
2. de préparer un baume appliqué autour des yeux permettant de voir dans la nuit pendant environ une heure ;
3. de révéler d'éventuelles traces de magie récentes au sol lorsqu'elles sont broyées puis dispersées.

Le groupe décide de conserver les fleurs.

---

## La nuit

Tout le monde dort au Pétale Doré.

Pendant la nuit :

- Baba espionne Ponsard à travers une fissure dans le mur ;
- Livia dort dans un pot de fleurs ;
- tous les personnages récupèrent :
  - tous leurs points de vie ;
  - leurs emplacements de sorts ;
  - leurs compétences.

---

## Le départ de Martha

Au réveil, Martha est déjà partie.

Avant son départ, elle laisse :

- un médaillon portant une patte d'ours ;
- destiné à Alias.

Ponsard remet le médaillon à Zarock.

Si le groupe retrouve Alias, il devra lui remettre ce médaillon.

---

## Départ du Pétale Doré

Le groupe prend un dernier petit-déjeuner.

Mintaros fournit :

- des provisions pour deux jours ;
- du vin infusé pour le voyage.

Bois paie 5 PA pour remercier l'équipage.

Le groupe quitte ensuite le Pétale Doré.

---

## Arrivée au carrefour

Le groupe arrive à un croisement.

Trois directions sont indiquées.

| Direction | Destination                    |
| --------- | ------------------------------ |
| Nord      | Village de Lunebois            |
| Est       | Bois de B…so…e                 |
| Ouest     | Temple de T…L… (panneau abîmé) |

Les personnages observent également :

- un immense arbre au loin semblant avoir bougé ;
- une forêt très sombre où plusieurs yeux les observent avant de disparaître.

Le groupe choisit finalement de se rendre à Lunebois.

---

## Arrivée à Lunebois

Après une vingtaine de minutes de marche, les personnages atteignent le village.

Ils découvrent :

- un pont traversant une rivière ;
- des maisons en bois, pierre et paille ;
- un vieux puits au centre du village ;
- plusieurs tentes de fortune ;
- une grande tente proche de l'entrée.

Le village paraît pourtant presque désert.

Ils remarquent :

- des rideaux qui bougent ;
- une porte qui claque ;
- une silhouette observant le groupe avant de disparaître.

La session se termine alors que les personnages pénètrent dans Lunebois.
