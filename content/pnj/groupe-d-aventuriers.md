## Généralités

| Élément     | Informations                         |
| ----------- | ------------------------------------ |
| Nom         | Inconnu                              |
| Composition | Plusieurs aventuriers, dont un moine |

## Description

Aucune description physique détaillée.

## Informations données

Ils expliquent avoir :

- affronté une liche ;
- perdu deux compagnons ;
- vaincu la liche.

Ils racontent également que leur dragon allié :

- les avait aidés ;
- a été traversé par une lumière bleu clair ;
- est devenu incontrôlable ;
- les a menacés avant de disparaître.

## État en fin de session

Le groupe se téléporte avant le début de l'aventure.
